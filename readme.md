# Интернет-магазин на Django

Этот проект представляет собой интернет-магазин, который будет разрабатываться и улучшаться в течение курса. Проект включает в себя настройку Django, создание приложения, работу с шаблонами и реализацию контроллеров.


### Установка

1. Клонируйте репозиторий:

   ```bash
   git@github.com:MaksimCharin/django_basics.git

2. Установите все зависимости, описанные в файле pyproject.toml, выполнив команду:
    ```bash
   poetry install

3. Для запуска сервера выполните команду в терминале:
    ```bash
   python manage.py runserver

4. Для остановки сервера воспользуйтесь комбинацией клавиш: 
    ```bash
   CTRL + C
